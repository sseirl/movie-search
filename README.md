Movie Search App 🎬
About

A movie search application that lets you:

Browse movie posters

Search for movies by title

View movie descriptions

Installation

Clone the repository:

git clone https://github.com/sseirl/movie-search.git


Go to the project folder:

cd movie-search


Install dependencies:

npm install


Run the project:

npm run dev

Usage

Browse movies on the homepage

Type the movie name in the search bar

Click a movie to see its description

Technologies

React

CSS

Movie API (e.g., OMDB or TMDB)
